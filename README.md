# VENU

An Android app for discovering events happening near you. Browse what's going on around you on an interactive map, search and filter events, read and leave reviews, and manage your profile.

## Features

- **Sign in and accounts** with Firebase
- **Explore and search** nearby events
- **Interactive map** built on Google Maps
- **Reviews** for events
- **User profiles**

## Tech stack

- Kotlin + Jetpack Compose
- Firebase (data models for users, events, and reviews)
- Google Maps
- Gradle

## Team and workflow

Built by a team of three in Spring 2026. We worked in feature branches and peer-reviewed every pull request before merging.
